# 阪神タイガースログ

このレポジトリは、学習ログアプリに育てるための土台として使います。

阪神タイガースの試合結果とメモを、日付ごとに記録するアプリです。記録はブラウザーの`localStorage`に保存されます。

## 使い方

`index.html`をブラウザーで開くと使えます。日付と今日の記録を選び、メモを入力して保存してください。同じ日付の記録を保存すると上書きされます。

## 機能

- 試合結果を「勝ち」「負け」「引き分け」「試合なし」「中止」から選択
- 日付ごとに記録を保存・編集・削除
- メモの検索
- 試合結果での絞り込み
- 結果ごとの記録数を表示

## 保存データ

保存キーは`hanshin-tigers-log.entries.v1`です。記録は次のような配列で保存されます。

```json
[
  {
    "id": "example-id",
    "date": "2026-09-29",
    "result": "win",
    "note": "逆転勝ち！",
    "createdAt": "2026-09-29T10:00:00.000Z",
    "updatedAt": "2026-09-29T10:00:00.000Z"
  }
]
```
